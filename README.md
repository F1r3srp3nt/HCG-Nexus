# HCG Nexus

An HCG command panel with searchable shortcuts, workspaces, recent actions,
HCG integration status and settings. It uses obsidian surfaces,
brushed-chrome hairlines and restrained cyan light. It ships in two
separately built forms:

| Route | What you get | Build | Docs |
|---|---|---|---|
| **1. Standalone app** | iPhone/iPad app (sandboxed). Workspaces, shortcuts, search, recents; **link** shortcuts open via iOS. **Connected Devices** (HCG Device Link) pairs with your HCG Server and shows shared reports. Shows an **APP MODE** badge; no system-wide overlay. | `HCGNexus.xcodeproj`, scheme **HCGNexus** (Xcode, or HCG Executable Maker → IPA) | [`docs/STANDALONE-APP.md`](docs/STANDALONE-APP.md) |
| **2. Jailbreak package** | System-wide cyan edge handle over any app, opening apps by bundle ID, Settings › HCG Nexus. | Theos `.deb` via `scripts/build-jailbreak-deb.sh` on a Mac (or the manual *Build package* workflow) | [`docs/INSTALL-AND-RECOVERY.md`](docs/INSTALL-AND-RECOVERY.md) |

Both routes share `Sources/Core` and `Sources/Panel`. They never share data:
the app keeps its own sandboxed store, separate from the tweak's preferences
and the preview harness.

> **Status:** 0.2.0, first device release candidate. What works and how it
> was verified: [`docs/FEATURES.md`](docs/FEATURES.md). First run on the
> phone: [`docs/DEVICE-CHECKLIST.md`](docs/DEVICE-CHECKLIST.md).
> * **Jailbreak package:** confirmed target **iPhone 13 Pro · iOS 16.5 ·
>   Dopamine (rootless) · ElleKit · Sileo**. Its Xcode-built rootless package
>   passes the strict arm64e ABI check.
> * **Standalone app:** Xcode 26.6 builds it for the simulator and as an
>   unsigned device build (minimum iOS 14.0). Its 8 unit tests pass and it
>   launches on the simulator ([`docs/VALIDATION.md`](docs/VALIDATION.md)).
> * **Neither route has run on a physical device yet.** The jailbreak package
>   ships **disabled**.

## Quick start

```sh
# Standalone app (Mac with Xcode)
open HCGNexus.xcodeproj            # scheme HCGNexus → pick a simulator → Run

# Jailbreak package (Mac with Xcode + Theos)
scripts/build-jailbreak-deb.sh     # verified .deb in packages/rootless/; nothing is installed
gmake package FINALPACKAGE=1 HCG_ENV=rootless   # same package, plain Theos (GNU Make 4+)

# Checks (Linux or Mac)
scripts/check.sh                   # add THEOS=… to also compile/link the app target
```

## Implemented in the jailbreak package (milestone 1)

* **Edge handle.** Right or left side, adjustable position and visibility.
  The touch target is 30×96 pt around a thin sliver. It is kept clear of the
  status bar and Notification/Control Centre pull zones and of the home
  indicator, and optionally above the keyboard area.
* **Opening and closing.** Tap or swipe inward to open. Close with the close
  button, an outside tap or the VoiceOver escape gesture. A state machine
  coalesces rapid taps. Touches outside the handle pass through to the app.
* **System layout.** Safe areas are handled, and the panel moves above the
  SpringBoard keyboard while typing. In SpringBoard the canvas rotates itself
  using `activeInterfaceOrientation`, verified at runtime.
* **Lock behaviour.** The overlay hides on lock, screen off and the cover sheet,
  even after Face ID unlock on the lock screen, and fails closed when the lock
  state is unknown. The window is never "secure", so it cannot draw over the
  lock screen. Nothing bypasses authentication.
* **Workspaces.** Create (from a preset or empty), rename, reorder and delete,
  stored locally with no login required. Presets: Command, Developer, Studio and
  Infrastructure. They only organise shortcuts.
* **Shortcuts.** Apps by bundle ID, links by URL, and HCG integrations, with
  validation and search across all workspaces.
* **Launch adapter.** Uses `LSApplicationWorkspace`, verified at runtime, off
  the main thread. Missing apps, links nothing can open, unconnected
  integrations and an unavailable launcher each give an actionable error with a
  shortcut to the fix.
* **HCG integrations.**
  * Terminal and News open their apps once enabled.
  * Server and Executable Maker are not offered: they have no
    phone-reachable contract yet.
  * No credentials are stored and no schemes are invented. The standalone
    app's Connected Devices is the one exception: it keeps its own HCG Connect
    sign-in in the Keychain.
  * See [`docs/INTEGRATIONS.md`](docs/INTEGRATIONS.md).
* **Settings.** Available in the panel and in the Settings app:
  * enable switch
  * handle side, position, visibility and keyboard zone
  * animations and haptics
  * integrations
  * workspace management
  * clear recents
  * reset (keeps the enabled state and workspaces)
  * diagnostics and version
* **Disabled means off.** When disabled, the panel closes, the window is hidden
  and nothing intercepts touches. Workspaces are kept. While disabled since
  launch, SpringBoard only reads preferences and listens for two Darwin
  notifications: no window, panel or lock monitor is created.
* **Accessibility.** Dynamic Type, VoiceOver labels and hints, a modal panel,
  custom actions for rename/delete, Reduce Motion (fade instead of slide),
  Reduce Transparency (solid surfaces) and Increase Contrast.
* **Recovery.** Settings entry, kill-switch file, package-manager uninstall.
  No automatic respring anywhere.

## Install and recover (jailbreak package)

Install the verified `.deb` with your package manager and respring yourself.
Then enable it in **Settings › HCG Nexus**. To disable it, turn that switch off.
To remove it, uninstall **HCG Nexus** in the package manager. Full steps:
[`docs/INSTALL-AND-RECOVERY.md`](docs/INSTALL-AND-RECOVERY.md).

## Known limitations

* **Standalone app is sandboxed.** It opens links only. App shortcuts by bundle
  ID and the system-wide overlay need the jailbreak package, and the app says
  so instead of pretending.
* **Executable Maker shows one route per folder.** With `HCGNexus.xcodeproj`
  present it offers the iOS-app (IPA) route; its Theos route is not offered for
  this repo. Build the `.deb` with `scripts/build-jailbreak-deb.sh`.
* **iOS 14.x device builds of the app** need an Xcode whose SDK still allows
  deployment target 14.0.
* **arm64e ABI.** Packages built on Linux have an old-ABI arm64e slice and must
  not be installed on the iPhone 13 Pro. Use the Xcode-built package from the
  *Build package* workflow or a Mac.
* **Unverified SpringBoard assumptions:**
  * window level `999`
  * orientation source and rotation direction
  * keyboard focus for text fields inside SpringBoard
  * `LSApplicationWorkspace` selectors
  * cover-sheet selectors
* **Keyboard in other apps.** SpringBoard cannot see another app's keyboard
  frame, so "Keep above keyboard" uses a fixed upper zone instead.
* **Notification Centre.** If Notification Centre is pulled down while unlocked,
  it is detected when the handle is next touched, not immediately (no hook is
  installed for it).
* **Preview harness.** A simulation only; its launches are simulated, and it
  has never been executed.
* **Integrations.** No live status, metrics or deep links, because no contracts
  exist for them yet.
* **Concurrent edits.** Settings.app and the panel editing workspaces at the
  same moment resolve as last writer wins.
